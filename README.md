# 💰 Бот учёта расходов

Телеграм-бот, который считает личные траты. Пишешь ему обычным текстом —
`кофе 300`, `такси 450 вчера`, `аренда 45к 01.08` — он сам вытаскивает сумму,
дату и категорию, а потом показывает, куда ушли деньги.

Python 3.11+, [aiogram 3](https://docs.aiogram.dev), SQLite. Внешних сервисов не
требует, данные лежат в одном файле рядом с ботом.

## Что умеет

**Запись траты одним сообщением.** Понимает разный порядок слов и форматы сумм:

| Сообщение              | Что запишет                          |
|------------------------|--------------------------------------|
| `кофе 300`             | 300 ₽, категория «Кафе», сегодня     |
| `450 такси до дома`    | 450 ₽, «Транспорт»                   |
| `продукты 1 250,50`    | 1 250,50 ₽, «Продукты»               |
| `аренда 45к`           | 45 000 ₽, «Жильё»                    |
| `кино 800 вчера`       | 800 ₽ вчерашним днём                 |
| `подарок 3000 05.08`   | 3 000 ₽ за 5 августа                 |
| `кофе 300р` / `300 ₽`  | валютные суффиксы игнорируются       |

**Автокатегории с обучением.** Категория подбирается по ключевым словам. Если
бот ошибся — жмёшь «✏️ Категория», выбираешь правильную, и слово из заметки
закрепляется за ней: в следующий раз бот не промахнётся.

**Отчёты.** `/stats` — сводка с разбивкой по категориям, бар-чартом, средним
днём и прогнозом на месяц. Период переключается кнопками: день / неделя /
месяц / всё время.

**Лимиты.** `/limit 60000` — общий бюджет на месяц, `/limit Кафе 8000` — по
категории. При добавлении траты бот предупредит на 80% лимита и на перерасходе.

**Напоминания.** `/remind 21:00` — каждый вечер напомнит записать траты;
сколько нужно напоминаний, столько и добавишь. Работают по часовому поясу
пользователя, переживают перезапуск бота и не задваиваются. Если траты за день
уже записаны, напоминание не придёт (отключается в `/reminders`). Первого числа
к напоминанию добавятся итоги прошлого месяца с топ-3 категорий.

**Ещё.** `/last` — последние траты с кнопками удаления, `/undo` — отменить
последнюю, `/export` — выгрузка всех трат в CSV (открывается в Excel без
плясок с кодировкой), `/currency` и `/tz` — валюта и часовой пояс.

## Запуск

Нужен только Python 3.10+ и токен бота от [@BotFather](https://t.me/BotFather)
(в Telegram: `/newbot` → имя → username → он пришлёт строку вида
`8123456789:AAH-…`).

**Одной командой.** Скрипт сам создаст окружение, поставит зависимости,
спросит токен и запустит бота:

```bash
./run.sh            # macOS и Linux
```

Под Windows — двойной клик по `run.bat`. Токен сохранится в файл `.env`, при
следующих запусках его не спросят. Бот работает, пока открыто окно терминала;
остановить — Ctrl+C.

**Несколько ботов сразу.** Если рядом лежат папки с другими ботами такого же
устройства, `start-all.sh` (или `start-all.bat`) поднимет их все: он смотрит в
соседние папки и запускает каждую, где есть `bot/main.py` и свой `.env`. Под
Windows каждый бот получит своё окно, под macOS и Linux все пишут в одно, с
пометкой, кто есть кто, а Ctrl+C останавливает сразу всех.

**Вручную**, если хочется контролировать шаги:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env     # и вписать BOT_TOKEN
python -m bot.main
```

Бот работает на long polling — публичный адрес и вебхуки не нужны, достаточно
машины с доступом в интернет.

### Переменные окружения

| Переменная         | По умолчанию        | Зачем                                  |
|--------------------|---------------------|----------------------------------------|
| `BOT_TOKEN`        | —                   | Токен от [@BotFather](https://t.me/BotFather), обязателен |
| `DB_PATH`          | `data/expenses.db`  | Файл базы SQLite                       |
| `DEFAULT_TZ`       | `Europe/Moscow`     | Часовой пояс новых пользователей       |
| `DEFAULT_CURRENCY` | `₽`                 | Валюта новых пользователей             |
| `LOG_LEVEL`        | `INFO`              | `DEBUG` / `INFO` / `WARNING`           |

### Команды

| Команда                    | Что делает                              |
|----------------------------|-----------------------------------------|
| `/stats`                   | Сводка расходов с переключением периода |
| `/last`                    | Последние 10 трат                       |
| `/undo`, `/del 42`         | Удалить последнюю трату / по номеру     |
| `/export`                  | Выгрузка в CSV                          |
| `/cats`                    | Категории и их ключевые слова           |
| `/addcat 🍕 Пицца, додо`   | Добавить категорию                      |
| `/delcat Пицца`            | Удалить (траты уедут в «Прочее»)        |
| `/kw Кафе, шаурма`         | Привязать слово к категории             |
| `/remind 21:00`            | Напоминать записывать траты             |
| `/remind off`              | Выключить все напоминания               |
| `/reminders`               | Список напоминаний и настройки          |
| `/limit`, `/limits`        | Лимиты на месяц                         |
| `/currency $`, `/tz`       | Валюта и часовой пояс                   |

## Как всё устроено

```
run.sh, run.bat   запуск в одну команду: окружение, зависимости, токен, старт
start-all.sh/bat  запуск всех ботов из соседних папок разом
bot/
  main.py         точка входа: бот, диспетчер, планировщик, long polling
  config.py       чтение .env
  db.py           SQLite-хранилище (суммы — целые копейки, без float)
  parsing.py      разбор текста: сумма, дата, подбор категории
  services.py     периоды отчётов, сборка отчёта, проверка лимитов
  reminders.py    планировщик напоминаний
  formatting.py   деньги, даты, бар-чарты
  keyboards.py    инлайн-клавиатуры
  middlewares.py  автосоздание пользователя, «сегодня» в его часовом поясе
  handlers/       common · expenses · reports · categories · budget · reminders
tests/            разбор текста, хранилище, напоминания, смоук-тесты хендлеров
```

Суммы хранятся в минорных единицах (копейках) целым числом, поэтому округления
не плывут. Данные разделены по `user_id` — один процесс спокойно обслуживает
несколько человек, у каждого свои категории, лимиты и валюта.

Состояние напоминаний живёт в БД, а не в памяти, поэтому перезапуск бота не
приводит ни к потерянным, ни к задвоенным сообщениям. Если бот был выключен в
момент напоминания, он отправит его при старте — но только если опоздание
меньше 20 минут, чтобы не будить ночью напоминанием из вчерашнего вечера.
Схема БД дополняется на месте: старая база открывается новой версией без
ручных миграций.

## Тесты

```bash
python -m unittest discover -s tests -t .
```

66 тестов, сети не требуют: хендлеры прогоняются через диспетчер с фейковым
ботом, который вместо HTTP-запросов записывает ответы, а планировщику
подставляется время, чтобы проверить и часовые пояса, и защиту от повторов.

## Что можно докрутить

- Учёт доходов и баланса, а не только трат
- Регулярные траты (подписки) и напоминания в начале месяца
- Графики картинкой вместо текстовых бар-чартов
- Общий бюджет на несколько человек
